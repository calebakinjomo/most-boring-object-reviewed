A [make.fun](https://make.fun) bounty entry for **The Most Boring Object, Reviewed in One Line** — one line, at most 200 characters, reviewing the most boring everyday object, funny and true.

## The review

> The dustpan: sweeps up everything except the last line of dust, which it escorts back onto the floor like a bouncer.

The dustpan's one job is to collect dust, yet every sweep ends the same way: a thin last line escapes back onto the floor. The joke is the object's own dull failure, told straight.

## How it works

`main.py` writes the review to `/output/entry.txt`. The review is 116 characters of UTF-8 text — inside the 1–200 character gate, a single line.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
